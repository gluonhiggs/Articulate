## FIND USAGE ERRORS

Scan the transcript for genuine grammar and word-choice errors only.

An error is defined as follows:
- **wrong word choice (semantic):** word valid in isolation but wrong in context
- **wrong tense:** incorrect verb form for the time reference
- **wrong preposition:** wrong connector (in/on/at/for/since/during)
- **wrong article:** missing or incorrect (a/an/the confusion)
- **wrong word form:** adjective where adverb needed, noun where verb needed
- **redundant word:** removal leaves meaning and grammar fully intact. Some examples:
  - *Semantic:* duplicates meaning already present
    (e.g. "return back" → "return", "past history" → "history")
  - *Grammatical doubling:* double-marks a feature already expressed
    (e.g. "more better" → "better")
  - *Over-inserted article:* a/an/the where the noun takes none
    (e.g. "I enjoy the music" as a general statement → "I enjoy music")

For each error found, output one object in `usage_errors`.
If there are no errors, output an empty array.

Each object contains:
- `"word"` = single word from transcript (lowercase, exact)
- `"type"` = `"mistake"` (clear mistake) or `"caution"` (possible issue)
- `"correction"` = replacement word, or `""` if the word should be deleted
- `"explanation"` = brief reason, 10 words max

### STRICT SCOPE

Do NOT flag words as errors when they are grammatically valid and contextually appropriate,
even if a different word would sound more sophisticated or stylistically better.
Flag only when there is a clear violation: a grammar rule is broken,
or the word is semantically wrong for the context it appears in.
Pronunciation issues are out of scope here regardless.
